# Solutions Numbers

Telegram-бот + Mini App: перепродажа Telegram-аккаунтов с LZT Market с наценкой.
Покупатель пополняет баланс (CryptoBot/Send, xRocket, Tonkeeper, звёзды), выбирает
страну и лот, бот покупает его на LZT и выдаёт номер и код входа.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # заполнить BOT_TOKEN, WEBAPP_URL, ADMIN_IDS, LZT_TOKEN, платёжки
python main.py
```

Mini App нужен https-адрес (`WEBAPP_URL`), например `cloudflared tunnel --url http://localhost:8090`.
Без `LZT_TOKEN` маркет работает в **демо-режиме**: лоты выдуманы, покупки без денег.
Проверка без Telegram: `DEV_AUTH=1` в `.env` и `http://localhost:8090/?dev=1`. На проде держать `DEV_AUTH=0`.

Самопроверка денег (наценка, двойные зачисления, возвраты, промокоды, рефералы):

```bash
python selfcheck.py
```

## Текстовая версия

Тот же магазин прямо в чате, без Mini App (`textmode.py`): кнопки «Каталог» и «Профиль» в главном меню.
Регионы → страны (по 8) → лоты (по 6) → карточка → подтверждение → покупка; «Мои покупки» с кодом входа
и кнопкой «Не работает»; профиль с пополнением (суммы или своя), переводом другу, промокодом и друзьями.
Одно сообщение редактируется на месте. Если `WEBAPP_URL` не задан, бот работает только в текстовом режиме.
Проверка без Telegram: `python tools/test_textmode.py`.

## Экономика (мы всегда в плюсе)

| Что | Как |
|---|---|
| Цена | закупка LZT + 10 % (`MARKUP`), но не меньше закупки + 2 ₽ (`MIN_MARGIN_RUB`) |
| Акции | `/promo RUS 5` режет только наценку, цена не ниже закупки + 1 ₽ |
| Звёзды | ×2 к цене (`STARS_MARKUP`): выводятся через 21 день и по курсу ниже покупного |
| Покупка | деньги списываются сразу, LZT покупает с потолком цены; отказ LZT → автоматический возврат |
| Резерв | `RESERVE_SIZE=10` аккаунтов докупается заранее для мгновенной выдачи, не дороже `RESERVE_MAX_PRICE` |
| Валидность | резерв перепроверяется через гарантию LZT раз в 30 мин и перед продажей; кнопка «Аккаунт не работает» в течение `GUARANTEE_H` часов: невалиден → LZT возвращает нам, мы — покупателю |
| Конкурс | каждый день в `GIVEAWAY_HOUR` по МСК, приз — самый дешёвый аккаунт до 15 ₽, только если маржа за сутки покрывает приз |
| Рефералы | каждые `REF_GOAL=15` друзей (запустил по ссылке + подписан на канал) → аккаунт до 15 ₽, не больше 20 призов в сутки |
| Промокоды | `/code SALE 50 100`: 50 ₽ × 100 активаций, из вашего кармана |

## Команды админа

`/admin` — статистика (выручка, маржа, резерв, баланс LZT), `/promo`, `/give`, `/code`,
`/draw`, `/reserve`, `/emoji` (создать набор премиум-эмодзи из `assets/emoji`; нужен
Telegram Premium у владельца бота), `/broadcast текст`.

## Файлы

| Файл | Что внутри |
|---|---|
| `main.py` | точка входа: бот, HTTP, воркеры |
| `lzt.py` | клиент LZT: поиск, fast-buy, код входа, проверка гарантии, демо |
| `shop.py` | цены, витрина, «завоз», покупка, резерв, гарантия, конкурс, рефералы |
| `crypto.py` | CryptoBot, xRocket, TON, звёзды |
| `db.py` | SQLite, все деньги в копейках, атомарные списания |
| `bot.py` / `i18n.py` | меню с баннером и премиум-эмодзи, админка; русский + en, zh, hi, es, ar |
| `web.py` | API Mini App с проверкой initData |
| `webapp/` | Mini App без сборки: `app.js`, `styles.css`, `i18n.js`, флаги, иконки Lucide (ISC) |
| `tools/` | `fetch_icons.py`, `make_emoji.py` |

## Что сверить на первом боевом запуске

LZT не документирует строго ответы `fast-buy` (где лежат телефон и 2FA) и
`check-guarantee`. Код разбирает их защитно и пишет сырые ответы в лог —
на первой реальной покупке проверьте в логе, что телефон и пароль достались правильно.
