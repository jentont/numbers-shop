# Оформление бота в @BotFather

Всё для профиля лежит в `assets/brand/`. Тексты описания на 6 языках бот ставит **сам** при запуске
(`botprofile.py`): название, короткое описание, «Что умеет этот бот?» и команды. Вручную в BotFather
нужно только то, чего нельзя сделать через Bot API: юзернейм, аватарка, картинка описания и Mini App.

## 1. Название и юзернейм

| | |
|---|---|
| Название | **Solutions Numbers** |
| Юзернейм | **@SolutionsNumbersBot** (на 16.11.2026 свободен) |
| Запасные | @SolutionsNumberBot, @SolNumbersBot, @SolutionsAccountsBot, @SolutionsNumbers_bot |

`/newbot` → название `Solutions Numbers` → юзернейм `SolutionsNumbersBot`. Токен — в `.env` (`BOT_TOKEN`).

## 2. Аватарка

`/setuserpic` → выбрать бота → отправить `assets/brand/avatar_1024.png` **как фото** (не файлом).

## 3. Картинка над описанием

`/mybots` → бот → **Edit Bot** → **Edit Description Picture** → `assets/brand/description_640x360.jpg`
(Telegram требует ровно 640×360).

## 4. Mini App

1. `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → URL = ваш `WEBAPP_URL`.
2. Там же — фото превью: `assets/brand/miniapp_640x360.jpg`.
3. Кнопку меню «Market» бот ставит сам при запуске, если задан `WEBAPP_URL`.
4. Ссылка на политику конфиденциальности (BotFather → **Edit Bot** → **Edit Privacy Policy**):
   `WEBAPP_URL/privacy`. Условия: `WEBAPP_URL/terms`.

## 5. Права в канале

Добавьте бота **админом** канала из `CHANNEL` (достаточно права «Добавлять подписчиков» или любого
минимального) — без этого он не видит подписчиков и не может включить обязательную подписку.

## 6. Премиум-эмодзи

- Чтобы на кнопках были иконки, у владельца бота должен быть **Telegram Premium**.
- После запуска: `/emoji` создаст свой белый набор, `/emoji_list` покажет, какие иконки взяты из
  пака `tgiosicons`, а каких нет. Недостающие: `/emoji_set 📱` и премиум-эмодзи в том же сообщении.

## 7. Тексты (для справки — бот ставит их сам)

**Короткое описание (ru):** Telegram-аккаунты 50+ стран. Мгновенная выдача, цены на 10% выше маркета, гарантия 24 часа.

**Описание (ru):**
```
Solutions Numbers — маркет Telegram-аккаунтов 50+ стран.

— Россия +7, СНГ, Европа, Азия, Америка: фильтры и сортировка по цене
— Мгновенная выдача: номер ваш сразу после оплаты
— Код входа приходит прямо в приложение
— Каждый аккаунт проверен, гарантия 24 часа
— Оплата: CryptoBot, xRocket, Tonkeeper, Telegram Stars
— Конкурс каждый день и аккаунт бесплатно за друзей

Нажмите «Старт», чтобы открыть маркет.
```

Английский, испанский, арабский, хинди и китайский — в `botprofile.py`. Изменить текст: правите там,
перезапускаете бота — он обновит описание сам.

## 8. Баннер главного меню

`assets/banner.jpg` (1280×720) бот присылает над меню по умолчанию. Заменить на свои фото, гифку или видео
можно в `/admin` → «Главное меню». Исходники аватарки и баннера: `аватарки/аватарка numbers shop/`
(`python render.py` перерисует).
